# Premium portfolio art direction

## Objective
Build an original, high-end founder portfolio: credible, expressive, restrained, memorable. The site must communicate identity and substance in the first 10 seconds, and reward deeper exploration. Avoid imitating an agency template or a standard job-seeker resume.

## Required workflow
1. Inspect the existing repository, live deployment when accessible, content, assets, design system, routing, and deployment pipeline. Never assume the framework or which GitHub repo is live.
2. Create a concise creative direction before editing: audience, desired impression, visual references, palette, font roles, grid, imagery, interaction concept, and explicit anti-references.
3. Propose **two distinct directions** with one recommended direction. Explain the difference in typography, visual composition, and motion. Ask for approval before substantial redesign if the owner has not chosen.
4. Design mobile and desktop together. Avoid designing a desktop-only animation and then squeezing it into mobile.
5. Keep the site legible and functional with animations disabled.

## Reference study (inspiration, not cloning)
- Dennis Snellenberg — https://dennissnellenberg.com/ — cinematic portrait, large type, confident project reveals and page transitions. Take the pacing and clarity, not the exact layout.
- Olivier Larose — https://www.olivierlarose.com/ — editorial design-engineer portfolio, strong typography, purposeful whitespace and selected-work organization.
- Rauno Freiberg — https://rauno.me/ — exceptional attention to interaction details and software craft. Use for micro-interactions and restraint.
- Emil Kowalski — https://emilkowal.ski/ — minimal portfolio with crisp type and thoughtful motion. Use for readable hierarchy and restraint.
- Bruno Simon — https://bruno-simon.com/ — benchmark for originality and immersive interaction. Do NOT reproduce a 3D game unless a strong content reason and adequate time/budget exist.

## Visual rules
- Make a distinctive typographic decision: an expressive display face with a sober, highly legible text face; check licensing and performance.
- Use one editorial grid, strong alignment, purposeful negative space, and visual hierarchy.
- Prefer rich neutral backgrounds and one considered accent over generic blue-purple gradients.
- Use a high-quality real portrait if available, without inventing one or using an unapproved AI-generated likeness.
- Use actual project visuals, not generic stock images or fabricated product screenshots.
- Build bespoke project case-study layouts with role, year, problem, contribution, result, and artifacts.
- Avoid: glassmorphism as a default, endless card grids, rotating buzzwords, generic particle backgrounds, fake metrics, excess blur, and unprompted cursor gimmicks.
- Respect the existing site and preserve valid content, URLs, accessibility, and SEO.

## Deliverables
A written art-direction proposal, design tokens, component map, page sections, and reference-to-decision table. Explain why every notable visual choice belongs on this specific founder's site.
